# Decision packets

Plain-language proposals for the founders to read and decide. Each packet lays out options, cites
its sources, and ends with an empty, unsigned sign-off block (same format as
`fund/compliance/signoffs/TEMPLATE.md`) for whichever founders actually decide. None of these are
signed, and none of them change any config, ADR, gate, or the CLAUDE.md/TEAM.md/CODEOWNERS
governance files.
