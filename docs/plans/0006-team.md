2. **Whether the founders are on a Claude org plan with managed settings —
   verified against current docs, ADR-0030 not decided here.**
   Two independent mechanisms exist, per
   `https://code.claude.com/docs/en/managed-settings` and
   `https://code.claude.com/docs/en/server-managed-settings`:
   - **Endpoint-managed settings**: a `managed-settings.json` file (or MDM /
     OS-level policy) deployed to each developer's machine. This is a file
     on disk; the docs state no Claude plan requirement to use it — anyone
     with access to the machine (or MDM for it) can deploy one.
   - **Server-managed settings**: configured from
     `https://claude.ai/admin-settings/claude-code` and fetched by Claude
     Code automatically. The docs are explicit here: *"Server-managed
     settings are available for Claude for Teams and Claude for Enterprise
     customers"* and the Requirements section lists *"Claude for Teams or
     Claude for Enterprise plan"* plus the Owner or Primary Owner role.
   We do not know which plan either founder is on. If both are on individual
   (Pro/Max) plans, only the file-based endpoint-managed route is available
   without upgrading. ADR-0030 should record the founders' actual plan and
   pick a route once known — not decided here.

3. **Whether project plugins / private marketplaces exist per current
   docs, ADR-0031 not decided here.**
   Verified against `https://code.claude.com/docs/en/plugins/host-marketplace`:
   private plugin marketplaces exist today and need no particular Claude
   plan. You can host a `marketplace.json` catalog in a private GitHub repo,
   another private git host, a hosted URL, or a shared-filesystem directory,
   and grant access the same way you'd grant access to any private repo
   (SSH key or stored git credential). A repository-scoped registration
   (`claude plugin marketplace add ... --scope project`, committed to
   `.claude/settings.json`) shares it with everyone who works in the repo.
   Separately, *"On a Team or Enterprise plan, you can also distribute the
   marketplace through Organization settings > Plugins & skills"* on
   claude.ai — that route is plan-gated the same way server-managed
   settings are, but it is an alternative distribution channel, not a
   requirement for having a private marketplace at all. ADR-0031 should
   weigh whether a private marketplace is worth the packaging overhead for
   a two-person team versus keeping skills/agents/hooks as plain committed
   files — not decided here.
